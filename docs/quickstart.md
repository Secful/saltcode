# Quickstart

Get Salt Code connected to your AI coding assistant in under 2 minutes.

## Step 1 — Get your token

Sign up at [salt.security/getsaltcode](https://salt.security/getsaltcode). Your personal access token will arrive by email.

## Step 2 — Connect your tool

Visit the [interactive setup page](https://salt.security/getsaltcode/setup), paste your token, and click your AI coding assistant. Every install command will be pre-filled with your token.

## Step 3 — Verify the connection

In your AI coding assistant, run:

```
What security policies and guidelines are active?
```

Salt Code should respond with the list of 40 active policies. You're connected.

## Try it

```
Design me a Swagger spec for a delete-user API that authenticates 
via a key in the query string and passes the deleted user ID in 
the query string as well.
```

Watch Salt Code flag the security issues before you write a single line of implementation code.
